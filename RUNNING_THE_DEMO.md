# Running the demo – one-minute checklist

**URL:** <http://127.0.0.1:8765/> (opens automatically)

## 60 seconds before the interview
1. ☐ Laptop on power; Wi-Fi not required.
2. ☐ Double-click **START_MIZAN.bat** → wait for "Ready" and the browser tab (≈ 5–10 s after the first install).
3. ☐ Top strip shows a **green dot – "بيانات المصدر الرسمي / Official source data"** and *Latest observed month: September 2026*.
4. ☐ Click **وضع العرض / Presentation mode** (full-screen the browser with **F11**).
5. ☐ Click **جولة مدتها دقيقتان / 2-minute walkthrough** and step through once.
6. ☐ **إعادة الضبط / Reset demo** returns to the default (Arabic, Overview, presentation off).

## Suggested flow (2 minutes) – Overview
1. *Source:* every number is from the Department of Statistics' monthly CPI (2018 = 100).
2. *Latest:* CPI 115.82, annual inflation 2.73 %, monthly +0.16 % – matches the Department's 12 Oct 2026 release.
3. *Chart:* solid = official; dashed + bands = forecast with 80 / 95 % intervals.
4. *Evidence:* open **Model Arena** – models re-run at 153 past dates, scored on unseen months, final 24 months untouched.
5. *Honesty:* no statistical model significantly beats the naive baseline; the app says so.

## If something goes wrong
* Page blank → the black window was closed; run START again.
* Different port in the window → use the URL it prints.
* Stop everything → **STOP_MIZAN.bat** (or close the black window).
* Language: top-right button; Arabic is default. `?lang=en` in the URL forces English.
* Keyboard: Tab through controls; on a chart use ← → to read values, Esc to clear, Home/End to jump.
